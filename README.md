# La Fournée

Site de la boulangerie **La Fournée**, 12, rue des Halles.

Le site est en ligne : [nova-tutos.github.io/la-fournee](https://nova-tutos.github.io/la-fournee/)

## Contenu

- `index.html` : la page d'accueil, avec les horaires
- `produits.html` : les produits et leurs prix
- `contact.html` : l'adresse et les jours d'ouverture
- `style.css` : la mise en forme commune aux pages

## Voir le site sur son ordinateur

Clonez le dépôt, puis ouvrez `index.html` dans votre navigateur :

```
git clone git@github.com:nova-tutos/la-fournee.git
```
